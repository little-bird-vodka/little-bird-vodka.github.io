# PM4Bench project page

This repository hosts the PM4Bench project page at
<https://little-bird-vodka.github.io/PM4Bench/>.

The site is static and dependency-free. `index.html` redirects the account root
to the project page; all project assets live under `PM4Bench/` so the public URL
can later be moved without changing page-relative paths.

The page follows the paper's argument—controlled evaluation, OCR-bottleneck
diagnosis, and OCR-centric GRPO—rather than presenting the release process.
Its lead visual is the paper's opening teaser, rasterized at 2304 × 1056 for
browser delivery and linked to its full-resolution view.

The paper buttons point to arXiv v3, and the page includes a copy-ready BibTeX
entry matching the official arXiv citation.
